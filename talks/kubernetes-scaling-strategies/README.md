# Kubernetes Scaling Strategies

A practical overview of workload autoscaling, node capacity, resource sizing, and safe workload lifecycle behavior in Kubernetes.

## Preview

Run `npm run dev` from this directory and open http://127.0.0.1:5173/.

## Build and export

Run `npm run build`, `npm run pdf`, or `npm run handout` from this directory. Outputs are written to `dist/`.
