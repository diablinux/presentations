## Same core API
Pods, Deployments, Services, ConfigMaps and Secrets work the same way.

## Same declarative model
Describe the desired state in YAML; controllers reconcile it.

## Same runtime benefits
Scheduling, self-healing, scaling and rolling updates.

## Same extensibility
CRDs and the Operator pattern are available in both.
