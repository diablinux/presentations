title: What Is a Hypervisor?
slug: hypervisors
layout: two-column
eyebrow: Core concept
notes: A hypervisor is software that creates and runs virtual machines by dividing CPU, memory, storage, and network among them. Type 1 runs directly on hardware; Type 2 runs as an application on a normal OS. The classification is a simplification.
---
## Type 1 (bare metal)

- Runs directly on server hardware
- Typical for data centers
- Example: VMware ESXi, KVM, Hyper-V

---

## Type 2 (hosted)

- Runs as an app on a normal OS
- Typical for laptops and labs
- Example: VMware Workstation, VirtualBox
